# Feria-Sim

Симуляція економіки, геополітики та подій для настільно-рольових кампаній **D&D** із підтримкою карт **[Azgaar Fantasy Map Generator](https://azgaar.github.io/Fantasy-Map-Generator/)** (`.map`, `.map.gz`, `.json`), інтерактивною веб-панеллю, CLI та експортом нотаток до **Obsidian**.

Працює на **Python 3.12+** виключно на стандартній бібліотеці — без сторонніх залежностей.

---

## Основні можливості

- **Економічне ядро ([`feria_sim/engine.py`](feria_sim/engine.py))**: 71 товар із виробничими рецептами, видобутком за біомами та родовищами, міжринковою торгівлею, сезонністю за широтою та динамічним ціноутворенням.
- **Політика й події ([`feria_sim/politics.py`](feria_sim/politics.py), [`feria_sim/events.py`](feria_sim/events.py))**: бюджети держав, податки, армії, дипломатія, війни, облоги, найманці, гільдії, ордени, 36 типів подій та поширення епідемій.
- **Універсальний імпортер карт Azgaar ([`feria_sim/importer.py`](feria_sim/importer.py))**: завантаження будь-яких `.map` / `.gz` / `.json` карт (із синтезом економіки для ванільних карт) та виділення векторних контурів суші, озер, держав, кордонів і річок (`map_geo.json`).
- **D&D-інструменти Майстра гри ([`feria_sim/dnd_tools.py`](feria_sim/dnd_tools.py))**:
  - роздрібні ціни таверн, крамниць, кузні, зброї й магії у кожному місті (курс `1:100`, `пм / зм / см / мм`);
  - калькулятор маршрутів подорожі (пішки, возом, верхи, кораблем) з оцінкою небезпеки й випадковими зустрічами;
  - генератор квестових гачків і чуток із поточних подій світу.
- **Веб-панель ([`feria_sim/web.py`](feria_sim/web.py), [`feria_sim/ui.html`](feria_sim/ui.html))**: інтерактивна векторна карта з 5 тепловими шарами, вкладка «D&D Стіл», редактор назв/лору (`data/overrides.json`), Undo-стек (`↩ Крок назад`) та слоти збережень.
- **Експорт до Obsidian ([`feria_sim/report.py`](feria_sim/report.py))**: автогенерація `Дашборд.md`, `Наступна сесія.md`, паспортів держав (з архівацією ліквідованих), ринків, товарів і хроніки.

## Швидкий старт

```powershell
# 1. Ініціалізувати світ з карти Azgaar (.map / .json)
python -m feria_sim init --map "шлях\до\карти.map" --year 1250 --era Н.Е.

# 2. Запустити веб-панель у браузері (http://127.0.0.1:8765/)
python -m feria_sim serve
```

### Корисні CLI-команди

```powershell
python -m feria_sim status                         # зведення світу та війн
python -m feria_sim run --months 3 --report        # прокрутити 3 місяці й оновити Obsidian
python -m feria_sim retail Несплоі                 # роздрібні D&D-ціни у місті
python -m feria_sim route Несплоі Буранвіле --mode horse
python -m feria_sim quests                         # квестові гачки
python -m feria_sim undo                           # відкотити останній крок
```
